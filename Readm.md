# Gerenciador de Tarefas em Java

Aplicação desktop desenvolvida em Java utilizando Swing para gerenciamento de tarefas.

## Funcionalidades

- Adicionar tarefas
- Marcar tarefas como concluídas
- Contador de tarefas pendentes
- Salvamento automático em arquivo
- Interface gráfica simples

## Tecnologias utilizadas

- Java
- Swing (interface gráfica)
- Programação Orientada a Objetos
- Manipulação de arquivos (FileWriter / BufferedReader)

## Objetivo

Projeto desenvolvido para prática de lógica de programação, POO e desenvolvimento de aplicações desktop em Java.
